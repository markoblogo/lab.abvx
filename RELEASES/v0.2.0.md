# ABVX Lab v0.2.0

ABVX Lab now has a repeatable quality gate and portable control-plane snapshot tooling.

## Changed

- Added CI and regression tests for the public static site.
- Added a scheduled and manually runnable verification of the deployed site and agent-discovery endpoints.
- Validated all HTML metadata, internal links, sitemap entries, JSON files, and image alternatives before deployment.
- Removed workstation-specific paths from generated public snapshots.
- Rebuilt registry, planning, proof, repo-card, status, and home-ledger views from current ABVX sources.
- Updated the README, runbook, and agent context with commands that can actually be run.

## Verification

- Python scripts compile cleanly.
- Unit tests pass on Python 3.12 and 3.14.
- The complete `docs/` site passes the local static-site verifier.
- GitHub Pages deployment and public URL verification are required before closing the release.
