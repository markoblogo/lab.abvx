ABVX Agent Skills

Portable, validation-gated skills for Codex-style project work: coding, research, frontend, audits, debugging, token economy, repo onboarding, durable context maintenance, loop engineering, browser verification, and standalone HTML artifact delivery for diagrams, briefs, plans, summaries, and explainers.

GitHub PyPI TestPyPI Homebrew tap agentsmd Lab catalog
Primary role Reusable agent capabilities
Where it fits

agentsgen describes the repo, ID describes the human, and ABVX Agent Skills describe repeatable workflows the agent can load on demand.

Best use case

Codex sessions that need compact expert behavior across discovery, planning, execution, repo onboarding, durable context, and one-file HTML deliverables without bloating every repo's AGENTS.md.

What it includes

  • SKILL.md files with trigger-rich descriptions and concise procedural rules.
  • SKILL_CARD.md files for intended use, attribution, risks, evaluation, and versioning.
  • A packaged CLI with list, install, validate, and audit-security commands.
  • SkillSpector-backed security audit policy with JSON reports, SARIF upload, baseline support, and publish preflight gating.

Quickstart

Install from PyPI

python -m pip install abvx-agent-skills
abvx-skills list
abvx-skills install dynamic-workflow-packets

Version 0.10.0 is published on PyPI and TestPyPI. It adds html-diagram-artifact and html-brief-artifact. Start a new agent session after installation so the skill description is discovered.

Homebrew

Install from the ABVX tap

brew tap markoblogo/tap
brew install abvx-agent-skills

homebrew-core is not the current install path for this project. The upstream submission was closed under the Homebrew core notability policy, so the maintained Homebrew channel is the ABVX tap.

Package status

Alternative install

git clone https://github.com/markoblogo/abvx-agent-skills
cp -R abvx-agent-skills/skills/* ~/.codex/skills/
