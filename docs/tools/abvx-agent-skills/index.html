ABVX Agent Skills

Portable, validation-gated skills for Codex-style project work: coding, research, frontend, audits, debugging, handoffs, browser verification, and skill evolution.

GitHub agentsmd Lab catalog
Primary role Reusable agent capabilities
Where it fits

agentsgen describes the repo, ID describes the human, and ABVX Agent Skills describe repeatable workflows the agent can load on demand.

Best use case

Codex sessions that need compact expert behavior without bloating every repo's AGENTS.md.

What it includes

  • SKILL.md files with trigger-rich descriptions and concise procedural rules.
  • SKILL_CARD.md files for intended use, attribution, risks, evaluation, and versioning.
  • A validation script and CI workflow for frontmatter, required files, placeholders, and basic secret patterns.

Quickstart

Install one skill into Codex

git clone https://github.com/markoblogo/abvx-agent-skills
cp -R abvx-agent-skills/skills/dynamic-workflow-packets ~/.codex/skills/

Start a new agent session after installation so the skill description is discovered.
