ABVX Agent Skills

Portable, validation-gated skills for Codex-style project work: coding, research, frontend, audits, debugging, token economy, repo onboarding, durable context maintenance, loop engineering, grilling, PRDs, issue slicing, triage, handoffs, browser verification, and skill evolution.

GitHub PyPI TestPyPI agentsmd Lab catalog
Primary role Reusable agent capabilities
Where it fits

agentsgen describes the repo, ID describes the human, and ABVX Agent Skills describe repeatable workflows the agent can load on demand.

Best use case

Codex sessions that need compact expert behavior across discovery, planning, execution, repo onboarding, and durable context without bloating every repo's AGENTS.md.

What it includes

  • SKILL.md files with trigger-rich descriptions and concise procedural rules.
  • SKILL_CARD.md files for intended use, attribution, risks, evaluation, and versioning.
  • A validation script, packaged CLI, and CI publish workflow for frontmatter, required files, placeholders, secret-pattern checks, and PyPI releases.

Quickstart

Install from PyPI

python -m pip install abvx-agent-skills
abvx-skills list
abvx-skills install dynamic-workflow-packets

The package is published on both PyPI and TestPyPI. Start a new agent session after installation so the skill description is discovered.

Package status

  • Published package name: abvx-agent-skills
  • CLI entrypoint: abvx-skills with list, install, and validate
  • Release path: GitHub Actions trusted publishing to TestPyPI and PyPI

Alternative install

git clone https://github.com/markoblogo/abvx-agent-skills
cp -R abvx-agent-skills/skills/* ~/.codex/skills/
