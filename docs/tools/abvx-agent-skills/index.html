Workflow layers

  • Access MCP and integrations connect external systems without putting every service contract into the prompt.
  • Execution CLI tools, scripts, CI, and local commands do deterministic work that can be logged and reviewed.
  • Discipline Skills decide when access and execution are allowed, which proof gates apply, and when a repeated workflow should become a reusable capability.
  • Review lenses assumption-excavation, pipeline-readiness-gate, and confidence-fragility-review turn agent-and-pipeline patterns into compact ABVX gates.
  • Exploration rabbithole-doc-exploration uses a local canvas for human-selected questions over AGENTS.md, skill docs, SET plans, and repomaps.

Top starts

  • idea-to-ship-gates Route vague product work through intent, spec, slices, proof, review, and release.
  • social-publishing-gate Draft, audit, approve, publish, and monitor social content without unsafe automation.
  • minimal-diff-builder Shortest correct implementation path for real coding work.
  • diagnose Debug around one signal, one hypothesis ladder, and narrow verification.
  • assumption-excavation Surface hidden assumptions before implementation or runner handoff.
  • pipeline-readiness-gate Select a compact pre/post/ship gate without adopting a full pipeline runtime.
  • confidence-fragility-review Check whether confident claims are backed by evidence before ship.
  • rtk-assisted-shell Best early win when shell output is burning your session budget.
  • rabbithole-doc-exploration Open dense agent docs in a local Rabbithole canvas before changing durable contracts.
  • frontend-product-builder Product-aware frontend work instead of generic component churn.
  • handoff Compact continuation briefs when work spans multiple sessions or operators.

Install

python -m pip install abvx-agent-skills
abvx-skills list
abvx-skills install dynamic-workflow-packets

Prefer this path when you want packaged install, validation, and CLI support.

Raw bundle

git clone https://github.com/markoblogo/abvx-agent-skills
cp -R abvx-agent-skills/skills/* ~/.codex/skills/

Use the raw bundle when testing local edits or when packaging is not the point.
