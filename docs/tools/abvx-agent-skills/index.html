ABVX Agent Skills

Portable workflow skills for agent sessions: compact guidance, validation gates, reflection consumers, and reusable one-file deliverables.

GitHub PyPI Homebrew tap Skills knowledge agentsgen
Primary role Reusable agent capabilities
Where it fits

ID carries human bootstrap, agentsgen emits repo surfaces, and this repo packages repeatable workflow behavior the agent can load on demand.

Best use case

Sessions that need sharper behavior without inflating every repo-local AGENTS.md with static instruction bulk.

Install channels

PyPI, TestPyPI, the ABVX Homebrew tap, or raw bundle install into ~/.codex/skills/.

Current extensions

OKF-style catalog export for navigation and a reflection-consumer path fed by agentsgen reflect ....

What it ships

  • SKILL.md files with trigger-rich descriptions and concise procedural rules.
  • SKILL_CARD.md files for intended use, attribution, risks, evaluation, and versioning.
  • A packaged CLI with list, install, validate, and audit-security commands.
  • SkillSpector-backed security audit policy with JSON reports, SARIF upload, baseline support, and publish preflight gating.

Capability lanes

  • Discovery and execution: project-context-bootstrap, graph-guided-code-reading, test-driven-execution, repo-debugging-ledger
  • Context and token discipline: lean-context-layout, token-frugal-mode, token-efficient-execution, compaction-survival
  • Frontend and artifacts: frontend-taste-layer, browser-verification, html-diagram-artifact, html-brief-artifact
  • Reflection and improvement: session-retrospective, skill-effectiveness-audit, skillopt-evolve-skills, web-quality-audit

For the full navigable inventory, use the skills knowledge page and the OKF-style catalog export.

Quickstart

Install from PyPI

python -m pip install abvx-agent-skills
abvx-skills list
abvx-skills install dynamic-workflow-packets

As of June 13, 2026, version 0.10.0 is live on both PyPI and TestPyPI. Start a new agent session after installation so newly installed skill descriptions are discoverable.

Homebrew

Install from the ABVX tap

brew tap markoblogo/tap
brew install abvx-agent-skills

The maintained Homebrew channel is the ABVX tap. homebrew-core is not the install path for this project after the upstream notability rejection.

Alternative install

git clone https://github.com/markoblogo/abvx-agent-skills
cp -R abvx-agent-skills/skills/* ~/.codex/skills/

Use this path when you want the raw skill bundle without packaging or when testing local edits before a release.

Reflection pipeline

From repo traces to reusable skill feedback

1. Producer

agentsgen derives reflection artifacts from local Codex sessions.

  • agentsgen reflect sessions .
  • agentsgen reflect skills .

2. Artifacts

The handoff surface lives under docs/ai/, not in raw transcript replay.

  • agent-signals.json
  • session-patterns.md
  • skill-usage.json
  • skill-effectiveness.md

3. Consumers

ABVX Agent Skills turns those artifacts into reusable retrospective and audit behavior.

  • session-retrospective
  • skill-effectiveness-audit
AGENTS.md_generator
  -> docs/ai/agent-signals.json
  -> docs/ai/session-patterns.md
  -> docs/ai/skill-usage.json
  -> docs/ai/skill-effectiveness.md
  -> abvx-agent-skills
     -> session-retrospective
     -> skill-effectiveness-audit

This is the current public reflection loop: AGENTS.md_generator produces repo-local reflection artifacts, and ABVX Agent Skills consumes them as portable workflow skills. The point is to learn from observed session patterns instead of just adding more static instruction surface.
