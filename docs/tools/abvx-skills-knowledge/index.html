ABVX Skills Knowledge

A lightweight knowledge entrypoint for the ABVX Agent Skills catalog, derived from an OKF-style markdown bundle. This is not the runtime skill format. It is a portable catalog layer for navigation, grouping, future viewers, and downstream agent consumption.

OKF bundle Catalog index ABVX Agent Skills
Bundle role Portable catalog layer
Source of truth

SKILL.md and SKILL_CARD.md remain canonical. The OKF bundle is derived export, not the instruction runtime.

Why it exists

It gives the skills repo a stable markdown+frontmatter knowledge surface that future viewers, search flows, and agents can consume without custom parsing.

Current bundle shape

  • catalog/okf/index.md as the root index
  • catalog/okf/skills/*.md with one concept per skill
  • catalog/okf/groups/*/index.md for grouped navigation
  • Frontmatter with type, title, description, resource, tags, canonical, source, status, and kind

What comes next

Experimental consumer first, richer viewer later

This page is the first public hook. The next likely step is a proper in-lab consumer that reads exported bundle structure and renders grouped search, graph, and related-skill navigation from the same portable catalog layer.
